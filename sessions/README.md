# Session and Operational Notes

This folder contains temporary session notes, task records, and operational artifacts that should not be mixed into the application source.

## Suggested use
- Project status notes
- Debugging summaries
- Deployment checklists
- Local environment documentation

## Keep out of runtime code
- Do not place app logic here.
- Keep secrets and credentials out of this directory.
- Use this folder for short-lived project management artifacts.
